ในโลกความเป็นจริง คอมพิวเตอร์ไม่มีความสามารถในการสร้าง "ความสุ่ม" (True Randomness) ด้วยตัวมันเองได้ เพราะคอมพิวเตอร์คือเครื่องจักรทางตรรกะที่ทำงานตามคำสั่งที่ถูกเขียนไว้ล่วงหน้าอย่างตายตัว (Deterministic)

เมื่อคุณต้องการตัวเลขสุ่มในระบบคอมพิวเตอร์ สิ่งที่คุณได้ไม่ใช่ความสุ่มจริงๆ แต่เป็น **PRNG (Pseudo-Random Number Generator)** หรือ "ตัวสร้างเลขสุ่มเทียม" ซึ่งทำงานอยู่บนพื้นฐานของ **ความสุ่มแบบคาดเดาได้ (Deterministic Randomness)**

## กลไกความสุ่มลวงตา (How it works)

PRNG ไม่ได้สุ่มอะไรเลยในเชิงกายภาพ แต่มันคือ **สมการคณิตศาสตร์** ที่ต้องการจุดเริ่มต้นจุดหนึ่งที่เรียกว่า **Seed (ค่าเริ่มต้น)**

- เมื่อคุณป้อนค่า Seed ลงในสมการ PRNG มันจะทำการคำนวณและพ่นตัวเลขออกมาเป็นชุด
    
- **ตรรกะความเป็นจริงคือ:** หากคุณใช้ค่า Seed เดิม และใช้สมการ PRNG ตัวเดิม คุณจะได้ "ตัวเลขชุดเดิมเหมือนกันทุกประการ" เสมอ 100%
    

ด้วยเหตุนี้ มันจึงถูกเรียกว่า Deterministic (ถูกกำหนดไว้แล้ว) และ Predictable (คาดเดาได้)

## มองมุมกลับแบบ Devil's Advocate: ทำไมเรื่องนี้ถึงอันตราย?

ถ้าเรามองตามหลักเหตุผล หากคุณกำลังเขียนโปรแกรมเกม การสุ่มไอเทมดรอปด้วย PRNG ปกติ (เช่น ดึงค่า Seed จากเวลาของระบบนาฬิกาคอมพิวเตอร์ - System Clock) ถือว่ายอมรับได้ เพราะผลลัพธ์ไม่ได้มีผลกระทบร้ายแรง

แต่ในมุมมองด้านความมั่นคงปลอดภัย (Cybersecurity) การยอมรับว่า PRNG คือ "ความสุ่ม" ถือเป็น **ตรรกะที่วิบัติและนำไปสู่ความหายนะ**

1. **จุดอ่อนของการใช้เวลาเป็น Seed:** โปรแกรมเมอร์หลายคนมักใช้เวลา (Timestamp) ระดับมิลลิวินาทีของเครื่องเซิร์ฟเวอร์มาเป็นค่า Seed หากแฮ็กเกอร์รู้ว่าเซิร์ฟเวอร์ของคุณสร้าง Session ID, Token หรือ Key ในเวลาใด แฮ็กเกอร์สามารถคำนวณย้อนกลับ (Reverse Engineer) เพื่อหาค่า Seed และสร้างตัวเลขชุดเดียวกันออกมาเพื่อสวมรอยเข้าระบบได้ทันที
    
2. **การเข้ารหัสที่พังทลาย (Broken Cryptography):** อัลกอริทึมการเข้ารหัสเครือข่ายจะไม่มีความหมายเลย หากกุญแจ (Encryption Key) ที่ใช้ล็อกข้อมูล ถูกสุ่มขึ้นมาจาก PRNG ธรรมดา เพราะคนที่รู้สมการและเดาค่า Seed ได้ ก็จะถอดรหัสได้ทั้งหมด
    

## ทางออกในโลกความเป็นจริง

เพื่อเบรกความเสี่ยงตามหลักตรรกะ ระบบที่ต้องการความปลอดภัยสูงจะไม่ใช้ PRNG ธรรมดา แต่จะใช้ 2 ทางเลือกนี้:

|**ประเภท**|**หลักการทำงาน**|**ความเหมาะสม**|
|---|---|---|
|**CSPRNG** (Cryptographically Secure PRNG)|ยังเป็นสมการคณิตศาสตร์ แต่ถูกออกแบบให้ยุ่งยากมากจนไม่สามารถคำนวณย้อนกลับเพื่อหาค่า Seed ได้ในเวลาอันสั้น และมีการดึงค่าเอนโทรปี (Entropy) จากระบบปฏิบัติการมาผสม|มาตรฐานที่ใช้ในระบบ Security, การสร้าง Token และ Key ในปัจจุบัน|
|**TRNG** (True Random Number Generator)|ทิ้งสมการคณิตศาสตร์ไป แล้วอาศัยปรากฏการณ์ทางกายภาพที่คาดเดาไม่ได้จริงๆ เช่น สัญญาณรบกวนทางคลื่นวิทยุ (Thermal noise) หรือการสลายตัวของสารกัมมันตรังสี|ใช้ในระบบที่ต้องการความปลอดภัยขั้นสูงสุดระดับสถาบันการเงินหรือการทหาร|

> **ข้อคิดตามหลักความเป็นจริง:** อย่าเชื่อใจฟังก์ชันอย่าง `Math.random()` ในการทำระบบที่ต้องการความปลอดภัย เพราะหลังบ้านของมันคือ Deterministic PRNG ที่พร้อมจะถูกคาดเดาได้เสมอเมื่อเงื่อนไขครบ
